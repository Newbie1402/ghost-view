# GhostView
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
User specified: Go standard library backend; semantic HTML, CSS and vanilla JavaScript frontend. Docker deployment.

## Users
People searching public social profiles across TikTok, Instagram and Facebook without switching apps or supplying platform credentials.

## Product Purpose
One interface for public profile and media discovery, with honest capability and access states.

## Operating Context
Search by username or supported profile URL; choose ambiguous candidates; view supported media; download only retrievable, permitted resources. Deterministic local demo fixtures validate the complete flow.

## Capabilities and Constraints
Never bypass private accounts, platform restrictions, authentication walls, CAPTCHAs or rate limits. No user passwords, cookies, tokens or sessions. Live integrations require verification; unavailable operations remain unavailable. Mobile and desktop must work with keyboard controls and reduced motion.

## Brand Commitments
GhostView. User selected an all-light interface. Neutral palette, centered search, rounded field, minimal visual noise.

## Evidence on Hand
Empty repository. No verified live integration or real user data. Demo content must be explicitly labeled.

## Product Principles
Public access only; truthful capabilities; minimal dependencies; security at trust boundaries.
